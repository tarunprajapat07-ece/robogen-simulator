    How ROBOGEN works

    1. Order

    The dashboard creates an order with a pickup, a destination and a payload, then assigns the robot.

    2. Navigate

    The robot plans a route across the warehouse map and drives to the pickup point.

    3. Avoid

    When an obstacle blocks the route, the robot stops and re-plans around it.

    4. Pick and transport

    The arm picks the payload (home, move, grip, lift) and the robot carries it to the destination.

    5. Place

    The arm places the payload, returns home, and the robot goes back to its dock.

    Prototype and final architecture

    Working prototype
    • ESP32 / Arduino control with motor drivers
    • 5-channel IR line following with PID steering
    • 5-DOF DC-motor arm with limit switches
    • Demo: line follow, pick, transport, place, stop
    Proposed final design
    • Raspberry Pi with ROS 2, SLAM and path planning
    • LiDAR, camera, IMU and wheel encoders
    • Shared warehouse map for multi-robot coordination
    • Detection range and arm accuracy to be measured experimentally

    This simulator is a virtual model. The LiDAR view and A* planner illustrate the proposed navigation design; they are not measurements from the physical prototype.
